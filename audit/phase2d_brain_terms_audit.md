## 2. 코드 경로 분석

### 2-1. `isDirectlyRelevantTerms` (ragSearch.ts:764)

```typescript
// line 785–787 — normalizedIssueGroups 중 하나
{
  query: /암|뇌경색|뇌출혈|심근경색|협심증|진단비|경계성|제자리/,
  terms: /암|뇌경색|뇌출혈|심근경색|협심증|진단비|경계성|제자리|진단확정/,
}
```

**문제:** `암`과 `뇌경색`이 동일 그룹에 묶여 있다.  
- 뇌경색 쿼리가 들어오면 이 그룹이 매칭됨
- `terms` 검사에서 청크 본문에 `암` 또는 `진단확정`만 있으면 통과
- 암 약관 청크(`암진단비`, `암의 진단확정`) → `암` 히트 → **통과**

같은 패턴이 `issueGroups`(line 810)에도 동일하게 반복됨.

결과: 뇌경색 쿼리로 terms_standards를 검색할 때 암 전용 약관 청크가 필터를 통과함.

### 2-2. `brainDiagnosisProfile` 필터 (index.ts:4424–4428)

```typescript
const excludedBrain = /도수치료|manual\s*therapy|M54|요통|…|심근경색|급성심근경색|NSTEMI|I21\.?4|심내막하심근경색/i;
const directBrain   = /뇌질환|뇌졸중|뇌경색|…|진단확정|약관|질병분류표/i;

if (excludedBrain.test(text)) return false;
if ((terms_standards||…) && !directBrain.test(text)) return false;
```

**문제 1 — `directBrain`이 과도하게 광범위:**  
`진단확정`과 `약관`이 `directBrain`에 포함되어 있음.  
암 약관 청크에는 "암의 **진단확정**이 병리 전문의에 의하여…" 처럼 두 키워드가 모두 존재
→ `directBrain` 테스트 통과 → 암 약관 청크가 뇌혈관 케이스에 제공됨.

**문제 2 — `excludedBrain`에 암 전용 패턴 없음:**  
`암의 진단확정`, `병리 전문의`, `조직검사(tissue)`, `C50|C코드|D코드` 등  
암 전용 패턴이 `excludedBrain`에 없어 명시적 차단이 불가능.

### 2-3. `directlyRelevantOfficial` 암 특화 필터 (ragSearch.ts:646–652)

```typescript
if (row.source_area === 'terms_standards' && generalCancerDiagnosisQuery(query)) {
  // 암과 무관한 약관 조항 차단 (실손/콩팥병/희귀난치성 등)
  if (!/암보험|질병보험|표준약관|암진단비|진단확정|…/.test(text)) return false;
}
```

암 쿼리 → 암 약관만 남기는 양방향 필터가 존재함.  
**뇌혈관 쿼리에 대응하는 동등한 필터가 없음.** 즉, 뇌경색 쿼리에는 이런 식의 전용 화이트리스트 필터가 구현되지 않았다.

**뇌혈관 366건 품질 분석 (샘플 5건 검토):**
- `33177e62`: 다질환 나열(①암 ②백혈병 ③뇌혈관…) — 전용 뇌혈관 약관이 아님
- `2b419321`: 신경계 후유장해 분류표 — 뇌졸중 *진단확정* 조항이 아님
- `51bca1d1~410d0807`: 약관 구조 목차/표지 문서

→ 366건 대부분이 뇌혈관을 나열 항목 중 하나로 포함하는 복합 약관 또는  
  장해 분류표이며, **뇌혈관질환 진단비 고유 약관 청크는 극히 드물 것으로 추정**.

암 276건은 "암의 진단확정은 병리 전문의에 의하여…" 형식으로 암 진단 요건을 명시하는
**전용** 청크가 다수 포함되어 있어 뇌혈관 쿼리에서도 높은 유사도를 기록함.

## 5. 수정 방향 (진단 목적 기록 — 이번 커밋에서 수정 안 함)

### 코드 수정 포인트

1. **`isDirectlyRelevantTerms` 그룹 분리** (ragSearch.ts:785–787)
   - `암` 그룹과 `뇌경색/뇌출혈` 그룹을 별도로 분리
   - 뇌경색 그룹의 `terms` 키워드: `뇌경색|뇌출혈|뇌혈관|뇌졸중|I63|I67|I60|분류표` (암 키워드 제거)

2. **`brainDiagnosisProfile` `directBrain` 축소** (index.ts:4428)
   - `진단확정` 제거 → `뇌진단확정|뇌혈관.*진단확정` 으로 구체화
   - `약관` 제거 → `뇌혈관.*약관|약관.*뇌혈관` 으로 구체화

3. **`brainDiagnosisProfile` `excludedBrain` 보강** (index.ts:4425)
   - `암의\s*진단확정|병리\s*전문의|조직검사|C50|암진단비|암보험` 추가

4. **뇌혈관 전용 terms_standards 화이트리스트 추가** (ragSearch.ts `directlyRelevantOfficial`)
   - `brainInsuranceQuery(query)` 신설
   - brain 쿼리 시 `terms_standards` → `뇌혈관|뇌졸중|뇌경색|뇌출혈|I63|I67|분류표` 미포함 청크 차단
