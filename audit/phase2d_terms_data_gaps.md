# 약관(terms_standards) 데이터 갭 누적 목록

목적: 코드 분기 개발 완료 후 일괄 임베딩 적재  
갱신 방법: 새 갭 발견 시 해당 섹션에 항목 추가 (덮어쓰기 금지)  
마지막 갱신: 2026-05-23

---

## 적재 우선순위 기준

| 등급 | 기준 | 처리 |
|------|------|------|
| **P0** | Ⅳ섹션 약관 0건 — 분쟁 핵심 조항 인용 불가 | 즉시 적재 |
| **P1** | 복합 약관만 매칭 — 전용 진단확정 조항 없음 | 분기 완료 후 적재 |
| **P2** | 가입 시점 약관 없음 — 연도 불일치 | 여유 시 적재 |

## 1. 갑상선암 (thyroid_cancer_benefit)

### ASSESS_048 — P2

| 항목 | 내용 |
|------|------|
| 문제 | 2012년 가입 갑상선암 특약 약관 청크 없음 → Ⅳ섹션에 2021/2026년도 약관만 매칭 |
| 필요 약관 | 2010~2014년 갑상선암 진단비 특별약관 (갑상선암 소액암 분류 전후 기준) |
| 핵심 조항 예시 | "갑상선암(C73)은 일반암과 구분하여 소액암으로 분류하며…" |
| 필요 형식 | 보험사별 갑상선암 특약 약관 (삼성생명, 교보생명, 한화생명 2010~2014) |
| 발견 케이스 | ASSESS_048 |

## 2. 뇌혈관질환 진단비 (brain_diagnosis_benefit)

### ASSESS_051~054, 057~062 — P0

| 항목 | 내용 |
|------|------|
| 문제 | 뇌졸중/뇌경색 진단확정 전용 약관 청크 부족 → Ⅳ섹션 0건 또는 복합약관(다질환 나열형)만 매칭 |
| 현재 DB 상태 | terms_standards 5,560건 중 뇌혈관 언급 366건이나 대부분 후유장해 분류표 또는 나열형 복합약관 |
| 발견 케이스 | ASSESS_051~054 (Ⅳ섹션 0건), ASSESS_057/058/062 (Ⅳ섹션 0건), ASSESS_060 (복합약관 1건) |

#### 필요 약관 ①: 뇌혈관질환 진단확정 조항

```
형식: "뇌혈관질환(I60~I69)의 진단확정은 의료법상 의사, 치과의사,
      한의사 자격을 가진 자가 뇌 영상검사(CT, MRI 등)에 의하여 내려진 진단으로 확인된 경우를 말한다."
필요 연도: 2010~2022년 표준약관 및 주요 보험사 약관
대상 보험사: 삼성화재, 현대해상, DB손보, KB손보, 메리츠화재
```

#### 필요 약관 ②: 뇌혈관질환 분류표 (I60~I69 명시)

```
형식: "【별표X — 뇌혈관질환 분류표】
      I60 지주막하출혈 / I61 뇌내출혈 / I62 기타 비외상성 두개내출혈
      I63 뇌경색증 / I65~I66 뇌전동맥 폐색 및 협착
      I67 기타 뇌혈관질환 (I67.1 미파열 뇌동맥류, I67.5 모야모야병 포함) / I69 뇌혈관질환의 후유증"
필요 연도: 2010~2022년 (I67 분류표 포함 시점 확인 필요)
```

#### 필요 약관 ③: TIA 제외 조항 (있는 경우)

```
형식: "일과성뇌허혈발작(G45, TIA)은 뇌졸중 진단비 지급 대상에서 제외한다."
또는: (이런 조항이 없음 = 약관에 TIA 제외 근거 없음도 중요한 증거)
```

## 3. 급성심근경색 (heart_diagnosis_benefit)

### 현재 상태 — 갭 없음

기본 약관 하드코딩으로 현재 Ⅳ섹션 정상 작동.  
가입 시점 연도별 약관 갭은 확인되지 않음 (ASSESS_101 기준).

> 향후 2010년 이전 가입 케이스에서 갭 발생 시 이 섹션에 추가.

## 4. 향후 카테고리 예비 섹션

새 분기(후유장해, 실손, 고지의무 등) 개발 시 약관 갭 발견되면 아래에 추가.

### 4-1. 후유장해 (disability_benefit) — 미개발

```
예상 갭: 장해분류표 구 버전 (2009년 이전 / 2015년 개정 전후)
          지급률 기준 변경 시점 약관
```

### 4-2. 실손의료 (실손보험) — 미개발

```
예상 갭: 1세대(~2009) / 2세대(2009~2017) / 3세대(2017~2021) / 4세대(2021~) 실손 약관
```

### 4-3. 고지의무 (disclosure_benefit) — 미개발

```
예상 갭: 계약 전 알릴 의무 조항, 중요한 사항 범위 약관
```

## 5. 적재 방법 (일괄 적재 시 참고)

```bash
# 1. 약관 PDF → 청크 분할 (scripts/chunkPolicyTerms.js 예정)
node scripts/chunkPolicyTerms.js --input data_sources/terms/ --source_area terms_standards

# 2. 임베딩 생성
node scripts/embedRagDatasetChunks.js --source_area terms_standards --upsert

# 3. 적재 확인
node scripts/checkRagData.js --source_area terms_standards

# 4. 검색 테스트
npm run rag:search:test -- "뇌졸중 진단확정 I63 약관"
npm run rag:search:test -- "갑상선암 소액암 특약 2012"
```
