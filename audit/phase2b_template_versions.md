## KOICD_SYSTEM_PROMPT v2 — 구조

```
[시스템 역할 설명]
[판단 지침 — 결정 방향성 먼저, 사정서 인용 가능성 분류]
⚠️ 경고: 피보험자 불리 판례를 유리한 법리로 가공 금지

출력 형식:
  판례번호: ...
  원심: ...
  결정 방향성: {원고 승소 | 원고 패소 | 일부 인용 | 파기환송-원고유리 | 파기환송-피고유리}
  사정서 인용 가능성: {핵심 인용 자료 | 보조 인용 자료 | 구별 논거용 | 역공 차단용}

  【사안의 사실관계】
  【쟁점】
  【XX법원 판단의 핵심】
  【사정서 활용 가이드 - {분류별 부제목}】   ← 수정 3 적용
  【사정서 인용 시 핵심 문구】
  【키워드】

[예시 — 암 관련 판례, 결정 방향성 + 사정서 인용 가능성 포함]
```

**활용 가이드 부제목 자동 결정 로직 (수정 3):**

| usage_classification | 【사정서 활용 가이드】 부제목 |
|---------------------|-----------------------------|
| 핵심 인용 자료 | `피보험자 측 핵심 근거 (직접 인용)` |
| 보조 인용 자료 | `피보험자 측 보조 근거` |
| 구별 논거용 | `보험회사가 본 판례를 인용할 경우 대응 방법` |
| 역공 차단용 | `사정서에 다음 차단 문구를 사전에 박아둠` |

## FSS_SYSTEM_PROMPT v2 — 구조

```
[시스템 역할 설명]
[판단 지침 — 결정 방향성 먼저, 사정서 인용 가능성 분류]
⚠️ 경고: 신청인 청구 기각 사례를 피보험자 유리 법리로 가공 금지

  결정번호: ...
  결정일자: ...
  분쟁 유형: ...
  결정 방향성: {신청인 청구 인용 | 신청인 청구 기각 | 일부 인용 | 조정 결렬}
  사정서 인용 가능성: {핵심 인용 자료 | 보조 인용 자료 | 구별 논거용 | 역공 차단용}

  【사안의 사실관계】
  【쟁점】
  【분쟁조정위원회 판단의 핵심】
  【사정서 활용 가이드 - {분류별 부제목}】
  【사정서 인용 시 핵심 문구】
  【키워드】

[예시 — 일본뇌염 FSS 2023-2호, 기각 + 구별 논거용으로 올바르게 표기]
```

## 형식 검증 규칙 (v2 기준)

### KOICD validateKoicdFormat — 12개 규칙

| # | 검증 항목 |
|---|-----------|
| 1 | 첫 줄 "판례번호:" |
| 2 | 【사안의 사실관계】 |
| 3 | 【쟁점】 |
| 4 | 【XX법원 판단의 핵심】 |
| 5 | 【사정서 활용 가이드】 |
| 6 | 【사정서 인용 시 핵심 문구】 |
| 7 | 【키워드】 |
| 8 | 총 길이 ≥ 1100자 |
| 9 | 원심 줄 존재 |
| **10** | **"결정 방향성:" 포함** ← 수정 5 신규 |
| **11** | **"사정서 인용 가능성:" 포함** ← 수정 5 신규 |
| **12** | **유효값 (핵심 인용/보조 인용/구별 논거용/역공 차단용 중 1개)** ← 수정 5 신규 |

### FSS validateFssFormat — 14개 규칙

| # | 검증 항목 |
|---|-----------|
| 1 | 첫 줄 "결정번호:" |
| 2 | 두 번째 줄 "결정일자:" |
| 3 | 세 번째 줄 "분쟁 유형:" |
| 4 | 【사안의 사실관계】 |
| 5 | 【쟁점】 |
| 6 | 【분쟁조정위원회 판단의 핵심】 |
| 7 | 【사정서 활용 가이드】 |
| 8 | 【사정서 인용 시 핵심 문구】 |
| 9 | 【키워드】 |
| 10 | 총 길이 ≥ 1100자 |
| 11 | 사정서 활용 가이드 내용 존재 (50자+) |
| **12** | **"결정 방향성:" 포함** ← 수정 5 신규 |
| **13** | **"사정서 인용 가능성:" 포함** ← 수정 5 신규 |
| **14** | **유효값 (핵심 인용/보조 인용/구별 논거용/역공 차단용 중 1개)** ← 수정 5 신규 |
